markdown# Информационная система управления библиотекой (Backend)

Профессиональный бэкенд-движок для автоматизации учета книжного фонда, управления пользователями и контроля выдачи активов. Проект реализован на чистом Python с использованием реляционной базы данных SQLite.

## Ключевой функционал системы
* **Архитектура БД (SQLite):** Разработана реляционная структура таблиц с поддержкой связей One-to-Many и Many-to-Many для сущностей (Книги, Авторы, Читатели, Логи выдачи).
* **Бизнес-логика (Python):** Реализованы алгоритмы проверки доступности экземпляров книг в реальном времени и автоматический расчет штрафных санкций за просрочку возврата.
* **Паттерн CRUD:** Написана модульная архитектура проекта с полным разделением логики обработки данных и ядра приложения.

## Стек технологий
* **Язык:** Python 3.x
* **База данных:** SQLite / SQL
* **Подход:** ООП (Объектно-ориентированное программирование), модульная архитектура

## Как запустить проект локально
1. Клонировать репозиторий.
2. Запустить главный файл системы:
```bash
python Main.py
```
